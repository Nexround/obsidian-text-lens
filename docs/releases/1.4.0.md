TextLens 1.4.0 adds experimental system native OCR alongside the default PaddleOCR engine. Recognition stays on your device, and an engine failure never switches your selected source.

## Changes

- Choose **PaddleOCR** or **System native OCR** in **Settings → TextLens → Recognition source**.
- On Windows, use the built-in Windows.Media.Ocr engine through Windows PowerShell 5.1, without downloading another runtime. Choose an installed language or use your configured system language. Oversized images are scaled proportionally, and ordinary spaces between Han characters are removed.
- On macOS, install the version-matched, ad-hoc signed Apple Vision helper from settings. The installer verifies SHA-256 and the helper version before atomic installation. Recognition works offline after setup and does not require Swift or Xcode.
- Native batches process one image at a time, show progress, enforce a 30-second image deadline, retain completed results after process failures, and clean up temporary files.
- Lock settings and prevent duplicate commands during recognition. Plugin unload cancels native processes and note writeback. Changed or closed notes are preserved, and failed images retain their previous OCR results when you rerun a note.

## Installation

Update through Obsidian Community Plugins, or copy `main.js`, `manifest.json` and `styles.css` into your vault's `.obsidian/plugins/text-lens/` directory.

PaddleOCR remains the default and uses its existing runtime/model setup. Windows native OCR requires an installed supported OCR language. For macOS native OCR, choose the source and click **Install / reinstall native helper**. Linux continues to use PaddleOCR.

The macOS helpers target macOS 11+ on arm64 and 10.15+ on x64. This Release includes both helper binaries, their individual `.sha256` files, and `ppu-bundle.cjs` for PaddleOCR setup.

## Experimental Status

Native OCR remains experimental. Windows subprocess recognition has been tested with English, Chinese, mixed text, Unicode paths, default and missing languages, blank/corrupt images, and oversized-image scaling. Both macOS architectures passed real Vision recognition, verified helper installation and offline reuse in [release preflight CI](https://github.com/Nexround/obsidian-text-lens/actions/runs/37587264266) on macOS 15.

Manual Obsidian acceptance on both platforms, minimum-version Mac testing, and testing Release downloads on Macs without developer tools remain pending. Single-column reading order is supported; complex columns and table layout reconstruction are outside this release. System default uses configured languages on Windows; macOS 13+ enables Vision language detection, while older Macs use a supported preferred language or English.
